# ИСКРА — Godot-версия

Полный порт игры на **Godot 4.3+** (GDScript). Геймплей, физика, уровни и
диалоги идентичны веб-версии: данные экспортируются из неё в
`data/game_data.json`.

## Как открыть

1. Скачай [Godot 4.3+](https://godotengine.org/download) (обычная версия, не .NET).
2. В менеджере проектов: **Import** → выбери файл `godot/project.godot` → **Import & Edit**.
3. При первом открытии Godot импортирует ассеты (пару секунд), затем жми **F5** (Run Project).

## Управление

Как в веб-версии: ← → / A D — движение, Пробел — прыжок, Shift/X — рывок,
E/Enter — диалоги, Esc — пауза.

## Структура

```
project.godot            — настройки проекта (960×540, canvas_items stretch)
main.tscn                — единственная сцена; всё строится кодом из main.gd
data/game_data.json      — конфиг, уровни (ASCII-экраны), диалоги
scripts/
  main.gd                — состояния, ввод, игровой цикл, камера
  game_data.gd           — доступ к данным + сохранения (user://)
  sheet_anim.gd          — аниматор спрайт-листов (строка=анимация)
  level_grid.gd          — сетка уровня, коллизии, шипы
  player.gd              — физика игрока (койот, буфер, двойной прыжок, рывок)
  moth.gd / walker.gd / flyer.gd — спутник и враги
  items.gd / checkpoint.gd / portal_gate.gd / moving_platform.gd
  bg_renderer.gd         — параллакс-фон (гориз. + верт.)
  tiles_renderer.gd      — отрисовка тайлов
  ui.gd                  — HUD, меню, диалоги, фейды
  particles_fx.gd        — частицы
  sfx.gd                 — звуки из assets/sfx/*.wav
assets/                  — спрайты/тайлы/фоны (PNG) и звуки (WAV)
```

## Ассеты

Раскладка листов та же, что в `../ASSETS.md`. Для глав 2–3 сейчас лежат
сгенерированные плейсхолдеры — замени файл по тому же пути, и Godot
подхватит его автоматически (проверь только совпадение размеров кадра).

## Изменение уровней

Уровни — ASCII-экраны в `data/game_data.json` (`CHAPTER_SCREENS`).
Легенда символов — в `../js/levels.js`. Если правишь веб-версию, перегенерируй
JSON скриптом из репозитория; можно править и JSON напрямую.
