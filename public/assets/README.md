# Ассеты Roost

Сюда кладётся весь твой дизайн. Файлы подхватываются автоматически по именам.
Ничего в коде менять не нужно — просто положи файл с нужным именем.

## Иконки — `assets/icons/`

| Файл | Размер | Где используется |
|------|--------|------------------|
| `logo.png` | ~ 320×80 (или SVG) | логотип на экране входа (если нет — покажется текст «Roost») |
| `app-icon.png` | 1024×1024 | иконка приложения на ПК и телефоне (для сборки) |
| `favicon.png` | 64×64 | иконка вкладки в браузере |
| `default-avatar.png` | 256×256 | аватар по умолчанию (опционально) |

## Фоны — `assets/backgrounds/`

| Файл | Размер | Где используется |
|------|--------|------------------|
| `auth.jpg` | ≥ 1920×1080 | фон экрана входа |
| `chat.png` | любой | фон области чата (опционально) |

После добавления фонов раскомментируй соответствующие строки
`--auth-bg` / `--chat-bg` в `public/css/theme.css`.

## Цвета и шрифты

- Цвета бренда меняются в `public/css/theme.css` (переменные `--brand` и др.).
- Свой шрифт: положи `.woff2` сюда и подключи через `@font-face` в `theme.css`.

> Форматы: PNG/SVG для иконок и логотипа, JPG/PNG для фонов.
> Просто скинь мне файлы — я разложу их по нужным именам и подключу.
