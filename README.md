# Музыкальные генераторы

Скрипты, которые собирают аранжировки и пишут MIDI-файлы для FL Studio.
Зависимостей для MIDI не нужно — только Python 3. Для рендера в звук
нужны `numpy`, `scipy` и `lameenc`.

## Хип-хоп: lyrical type beat 2010-2012

85 BPM, F# минор. Меланхоличное пиано с ревером, соул-чоп, boom-bap
барабаны с 808 и атмосфера винила — «дождливая» ностальгическая эстетика.

```bash
python3 generate_boombap.py                 # rainy_night_85.mid
python3 generate_boombap.py --key Dm        # другая тональность
python3 generate_boombap.py --guide         # что вешать в FL
python3 render_boombap.py                   # послушать: beat.mp3
python3 render_boombap.py --no-vinyl        # без винила и шума ленты
```

Структура 64 такта (~3:00): Intro 8 → Verse 16 → Hook 8 → Verse 16 →
Hook 8 → Outro 8. Дорожки: Piano, Piano Melody, Soul Chop, 808 Sub, Drums.

Гармония — `i – VI – III – v` (F#m9 – Dmaj9 – Amaj9 – C#m11). Минорная
пятая ступень вместо мажорной не даёт разрешения, отсюда ощущение
незакрытости. Барабаны: малый строго на 2 и 4, бочка синкопирована,
хэты со свингом и ролами в конце четырёхтактий.

Рояль синтезируется аддитивно, с негармоничностью струны: обертоны
уходят выше кратных частот (у A3 восьмой обертон на +22 Гц), верхние
гаснут быстрее нижних. Без этого пиано звучит как орган.

Винил, шум ленты и плавание высоты (wow/flutter) — шумовые слои, нот у
них нет: их делает рендерер или плагин RC-20 в FL.

## Клубный EDM

Три стиля, у каждого свой темп, басовый рисунок и барабаны:

| `--style` | Темп | Что это | Бас в дропе | Бочка |
|---|---|---|---|---|
| `future` | 150 | Future bass (Marshmello) | по стабам аккордов | half-time |
| `bass` | 140 | Тяжёлый dubstep-дроп | рваный гроул с прыжками | half-time |
| `house` | 128 | Bass house / клубный | офбит между бочками | в пол |

```bash
python3 generate_edm.py                      # future bass, 150 BPM
python3 generate_edm.py --style bass         # тяжёлый гроул-дроп
python3 generate_edm.py --style house        # bass house
python3 generate_edm.py --key Am --bpm 145   # любая тональность и темп
python3 generate_edm.py --guide              # какие синты вешать в FL

python3 render_audio.py --style house        # послушать до открытия FL
python3 render_audio.py --seconds 45         # быстрое превью
```

Структура: Intro → Verse → Build → **Drop** → Breakdown → Verse → Build →
**Drop** → Outro, 88 тактов (~2:20–2:45).

### Бас разложен на три слоя

Так делают в клубной музыке, чтобы низ читался и на телефоне, и на большой
системе — один широкополосный бас всегда превращается в кашу:

- **Sub Bass 808** — чистый синус, 35–52 Гц. Только фундамент, строго моно.
- **Reese / Growl Bass** — расстроенные пилы, 69–208 Гц, воббл фильтром и
  дисторшн. Это весь «рык», главный слой дропа.
- **Supersaw Chords** — от 250 Гц и выше, низ им обрезан.

Диапазоны не пересекаются: reese режется снизу на 85 Гц, суб сверху на
110 Гц. Оба сайдчейнятся от бочки.

## Гитарная песня «Я ведь не свят»

```bash
python3 generate_melody.py                # ya_ved_ne_svyat.mid
python3 generate_melody.py --no-drums
```

Em–C–G–D, 103 BPM. Темп, тональность и главный хук сняты с голосовой
записи автора.

## Как это попадает в FL Studio

1. Перетащи `.mid` в окно FL (или File → Import → MIDI file).
2. FL спросит про импорт — выбери разложить по отдельным каналам.
3. На каждый канал повесь свой синт или сэмплер. Ноты уже расставлены,
   остаётся звук: пресеты, сайдчейн, эффекты, мастеринг.

MIDI хранит только ноты — темп, длительности и высоту. Тембр, сведение и
мастеринг делаются в DAW, поэтому «звук как у Marshmello» получается из
связки: эти ноты + супер-пила + сайдчейн от бочки.

## Файлы

| Файл | Что делает |
|---|---|
| `midi_writer.py` | запись стандартного MIDI (SMF format 1), без зависимостей |
| `dsp.py` | общие кирпичи синтеза: фильтры, огибающие, реверб, вывод файлов |
| `generate_boombap.py` | хип-хоп бит → MIDI |
| `render_boombap.py` | рояль, соул-чоп, 808, boom-bap барабаны, винил → MP3 |
| `generate_edm.py` | аранжировка future bass / dubstep / house → MIDI |
| `render_audio.py` | супер-пила, reese-бас, сайдчейн → MP3 |
| `generate_melody.py` | гитарная песня Em–C–G–D → MIDI |

Отрендеренное аудио (`*.mp3`, `*.wav`) не коммитится — оно всегда
пересобирается скриптом.
