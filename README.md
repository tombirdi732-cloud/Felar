# Фелар: Сердце Мшистого Леса

2D-платформер на чистом HTML5 Canvas — без движков и внешних библиотек.

Изумрудное Сердце леса Фелар раскололось, и его осколки растащили слаймы.
Юный маг-хранитель Тэо отправляется по висячим островам, чтобы собрать
осколки и вернуть лесу свет.

## Как играть

Открой `index.html` в браузере или запусти любой статический сервер:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

### Управление

| Клавиша | Действие |
|---|---|
| ← → или A D | движение |
| ПРОБЕЛ / W / ↑ | прыжок (держи дольше — прыжок выше) |
| SHIFT / K | рывок — проходит сквозь врагов и шипы |
| ESC | пауза |

На сенсорных экранах появляются экранные кнопки.

### Правила

- Зелёных слаймов можно топтать сверху, оранжевые — колючие: только рывок.
- Шипастые лозы и ядовитые цветы ранят, падение в бездну возвращает на последний остров.
- Синие цветы — чекпоинты: лечат и запоминают точку возрождения.
- Прыгучие растения — батуты: подбрасывают выше обычного прыжка.
- Собери **все осколки** Сердца на уровне — откроется портал.
- Три уровня: Зелёная опушка → Висячие сады → Тропа шипов.

## Технически

- `js/game.js` — движок: физика (coyote time, jump buffer, рывок), камера,
  параллакс, частицы, светлячки, WebAudio-синтез звуков, экраны меню/сюжета.
- `js/levels.js` — данные трёх уровней и сюжетные тексты.
- `assets/` — спрайтшиты, собранные из исходных ассетов
  (кадры 512×512 обрезаны и упакованы, тайлсеты нарезаны на чанки).
- Прогресс сохраняется в `localStorage`.

## Ассеты

- **Blue Wizard** — анимации героя (idle / walk / jump / dash)
- **Slimes** — зелёный и оранжевый слаймы
- **Mossy Tileset** — острова, платформы, шипы, декорации, фоны
- **Plant Animations** — батуты, ядовитые цветы, чекпоинты, живые травы
- **Raven Fantasy Icons** — иконки интерфейса (сердца, осколки, зелья)
