# SCP-2983 «ИНЕЙ» — аддон для Garry's Mod

Играбельный SCP с ресурсом **Ледяное Ядро** вместо кулдаунов, шкалой
**Обморожения** на жертвах, контрплеем через тепло и «Обмороженными» слугами.

## Установка

1. Скопируй папку аддона в `garrysmod/addons/felar_scp2983/`
   (или залей как gmod-аддон в воркшоп — `addon.json` уже готов).
2. Перезапусти сервер / карту.
3. Стать ИНЕЕМ:
   - в чат: `!iney` (снять — `!uniney`)
   - или консоль: `scp2983_make` (себя) / `scp2983_make <ник>` / `scp2983_remove`
   - по умолчанию доступно только админам (`SCP2983.Config.AdminOnly`).

## Управление

| Клавиша | Способность | Ядро |
|--------|-------------|------|
| **ЛКМ** | Ледяной удар (+18 / +30 в спину) | 0 |
| **E** | Ледяной взрыв (5 м, +45 стаков, стан 1.5с, тушит огонь) | 35 |
| **R** | Цепи холода (гарпун тянет цель, +10 стаков/сек) | 25 |
| **F** (удержать) | Перерождение холода (из замороженного → Обмороженный) | 60 |

Пассивка **Ледяная тропа** работает сама: под ногами наледь, SCP по ней
быстрее, люди — скользят.

Клавиши меняются в `lua/scp2983/sh_config.lua` → `Config.Abilities.*.Key`.

## Ледяное Ядро (ресурс)

- Быстро восстанавливается в **тёмных** зонах (замеряется освещённость у глаз)
  и внутри **крио-зон** (энтити `scp2983_cryozone`, спавнится из меню Q).
- Медленно — в обычных, освещённых помещениях.
- **Убывает** рядом с огнём/источниками тепла и при горении.
- На нуле SCP медленный и слабый, кулаки без эффекта.

## Слабость: ТЕПЛО

Всё настраивается в `Config.Weakness`:

- **Термокостюмы МОГ** — гасят первые 40 стаков обморожения
  (`ThermalSuitModels` — впиши модели костюмов).
- **Зажигательные патроны** — x2 урона по SCP и обнуляют ядро
  (`IncendiaryWeapons` — впиши классы оружия).
- **Огнемёт** — оружие класса «сдерживание» (`FlamethrowerWeapons`).

## Что нужно докинуть (воркшоп / ассеты)

Аддон работает и без них (плейсхолдеры), но для полноты:

- **Модель ИНЕЯ** → `Config.PlayerModel`
- **Модель Обмороженного** → `Config.Thrall.Model`
- **Иконки способностей** → `materials/scp2983/icons/` (см. ниже)
- **Оружие сдерживания** (огнемёт, зажигательные патроны) — найти в воркшопе,
  вписать классы в `Config.Weakness`.
- **Звуки** → `Config.Sounds` (сейчас стоят стоковые из HL2).

## Иконки способностей

Положи PNG-файлы в `materials/scp2983/icons/`. Стиль — как в примере:
**белая тонкая обводка (line-art) на прозрачном фоне**, квадрат ~256×256.

| Файл | Название (в HUD) | Что рисуем |
|------|------------------|-----------|
| `ice_strike.png`  | Ледяной удар          | кулак/ладонь с ледяными шипами |
| `ice_blast.png`   | Ледяной взрыв         | взрыв-снежинка / круговая волна льда |
| `cold_chains.png` | Цепи холода           | ледяной гарпун / цепь с сосульками |
| `frost_reborn.png`| Перерождение холода   | силуэт во льду / раскол льда |

HUD сам подставит их: `[клавиша]` сверху, иконка в центре, название снизу.
Пока файлов нет — рисуется снежинка-плейсхолдер, ошибок не будет.

```
    sh_util.lua

    sv_passive.lua   ледяная тропа
    sv_weakness.lua  тепло / сдерживание

    cl_hud.lua       ядро + панель иконок
    cl_effects.lua   виньетка инея, ESP
  effects/           ледяные эффекты
  entities/scp2983_cryozone/  крио-зона
weapons/scp2983_hands.lua      ледяной удар (SWEP)
```
