# Tom | СтройАренда — аренда инструмента и техники между частными лицами

Сайт-классифайд (по модели Авито): владельцы размещают объявления о сдаче
инструмента и техники в аренду, арендаторы находят нужное через поиск и фильтры,
договариваются во встроенном чате и встречаются лично. **Платформа не
обрабатывает платежи и залоги** — расчёты происходят между пользователями
при встрече.

## Стек

| Слой | Технология |
|---|---|
| Фреймворк | Next.js 15 (App Router, Server Actions), React 19, TypeScript |
| Стили | Tailwind CSS 4 |
| БД / ORM | Prisma; SQLite в разработке, PostgreSQL в продакшне (смена `provider`/`DATABASE_URL`) |
| Изображения | sharp — сжатие/ресайз/WebP при загрузке |
| Авторизация | VK ID (OAuth 2.1 + PKCE) — основной способ; телефон + SMS-код — резервный |

## Быстрый старт

```bash
npm install                 # зависимости (+ prisma generate)
cp .env.example .env        # заполнить переменные
npx prisma db push          # создать схему БД
npm run db:seed             # структура категорий (только каталог, без контента)
npm run dev                 # http://localhost:3000
```

Продакшн: `npm run build && npm start`.

### Переменные окружения (.env)

- `DATABASE_URL` — SQLite для разработки, PostgreSQL для продакшна.
- `NEXT_PUBLIC_SITE_URL` — публичный адрес (OAuth-редиректы, SEO).
- `VK_CLIENT_ID`, `VK_CLIENT_SECRET` — приложение VK ID
  (redirect: `{SITE_URL}/api/auth/vk/callback`). Пока не заполнены,
  кнопка VK показывает подсказку, работает вход по телефону.
- `SMS_PROVIDER` — `dev` (код печатается в консоль сервера) или боевой
  провайдер, подключаемый в `src/lib/sms.ts` одной функцией.
- `ADMIN_PHONE` — номер, получающий права администратора при подтверждении
  (первичное назначение; далее управление через админ-панель).

## Реализованный функционал (по ТЗ)

- **Роли**: гость (просмотр/поиск), пользователь (объявления, чат, отзывы,
  избранное), администратор (модерация).
- **Авторизация**: VK ID с автозаполнением имени/фото; телефон + SMS-код;
  сессии в БД (cookie, 30 дней).
- **Верификация**: телефон (обязателен для размещения), документ →
  бейдж «Верифицирован» через проверку модератором (файл доступен только админу).
- **Объявления**: до 8 фото (сжатие в WebP), цена за сутки/неделю/месяц,
  залог, город/район, примерная точка на карте (округляется до ~1 км),
  условия; статусы активно / в аренде / архив; редактирование, снятие, удаление;
  заделы монетизации: поднятие и выделение (`promotedUntil`/`highlightedUntil`).
- **Каталог**: категории/подкатегории (редактируются в админке), поиск,
  фильтры (город, цена от–до, «только верифицированные»), сортировки
  (новые, цена ↑↓, рейтинг владельца), пагинация, ЧПУ-ссылки.
- **Карточка**: галерея, описание, условия, карта (OSM), блок владельца
  с рейтингом и датой регистрации, отзывы, «Написать», избранное, жалоба.
- **Чат**: привязан к объявлению, текст + фото, поллинг новых сообщений,
  список диалогов с непрочитанными, антифлуд.
- **Отзывы**: только между участниками диалога с перепиской
  (физическая защита от накрутки — уникальный ключ «диалог + автор»);
  рейтинг — строго среднее по отзывам; удаление — только модератором по жалобе.
- **Админ-панель**: очередь жалоб и заявок на верификацию, блокировка
  объявлений и пользователей, управление категориями.
- **Безопасность**: арифметическая капча при создании объявления (заменяется
  на reCAPTCHA/SmartCaptcha в `src/lib/captcha.ts`), rate-limit на SMS,
  сообщения, объявления и жалобы.
- **SEO**: ЧПУ-слаги, метатеги и OpenGraph, `sitemap.xml`, `robots.txt`
  (личные разделы закрыты от индексации).
- **Адаптивность**: mobile-first, проверено на вьюпортах 390px и 1280px.

## Бренд-активы (ТЗ п. 5)

Установлены активы заказчика (каталог `public/brand/`):

| Актив | Файл | Где используется |
|---|---|---|
| Логотип | `public/brand/logo.png` | Шапка, футер |
| Favicon | `src/app/icon.png` | Вкладка браузера |
| Иконки категорий (6 шт.) | `public/brand/categories/*.png` | Главная (`CategoryIcon`) |
| Бейдж верификации | `public/brand/verified.png` | `VerifiedBadge` |
| Заглушка «нет фото» | `public/brand/no-photo.webp` | `NoPhoto` |
| Фон главного экрана | `public/brand/hero.webp` | Hero-блок главной |
| OG-превью 1200×630 | `public/og.png` | Метатеги (сгенерировано из логотипа) |

Иконки категорий и бейдж обработаны из исходников заказчика: серый фон
переведён в прозрачность (стиль «неон» сохранён), поэтому они размещаются
на тёмных плитках `bg-ink-900`. Палитра сайта (`--color-brand-*` в
`src/app/globals.css`) соответствует логотипу: золото `#D99A2B` +
тёмный нави `#1D2531`. Мелкие интерфейсные иконки (поиск, чат, сердечко
и т.п.) — SVG в `src/components/Icons.tsx`.

## Наполнение контентом (ТЗ п. 9)

В репозитории и сиде **нет и не должно быть** фиктивных объявлений, отзывов,
пользователей или рейтингов. Сид (`prisma/seed.ts`) создаёт только структуру
категорий. Весь контент появляется исключительно из действий реальных
пользователей. Тестовые данные допустимы только в dev-окружении, с префиксом
«ТЕСТ» и по согласованию с заказчиком.
