# Discord-бот модерации медиа 🛡️

Бот следит за отправкой **изображений, GIF, стикеров-картинок и ссылок на гифки** (Tenor/Giphy, прямые ссылки на картинки). Каждое медиа анализируется vision-моделью Claude. Если на нём политика или другой запрещённый контент:

1. 🗑️ сообщение **удаляется**;
2. ⚠️ автору выдаётся **предупреждение** (в канале + в ЛС);
3. 🔇 после лимита предупреждений (по умолчанию 3) — **таймаут** (по умолчанию 60 минут).

> Discord не позволяет ботам блокировать сообщение *до* отправки — бот удаляет его сразу после появления (обычно за 1–2 секунды).

## Что проверяется

Категории задаются в `config.json` (можно менять/добавлять свои):

| Ключ | Описание |
|---|---|
| `politics` | политики, лозунги, партийная символика, протесты, пропаганда |
| `nsfw` | обнажёнка, порнография |
| `violence` | кровь, жестокость, реальное насилие |
| `extremism` | нацистская/террористическая символика |
| `drugs` | наркотики и их пропаганда |

Обычные мемы, аниме, игровые скриншоты и юмор не трогаются.

## Установка

```bash
pip install -r requirements.txt
```

### 1. Создай бота в Discord

1. [Discord Developer Portal](https://discord.com/developers/applications) → **New Application**.
2. Вкладка **Bot** → скопируй **Token**.
3. Там же включи **Message Content Intent** и **Server Members Intent** (обязательно!).
4. Вкладка **OAuth2 → URL Generator**: scope `bot`, права:
   - View Channels, Read Message History
   - **Manage Messages** (удалять сообщения)
   - **Moderate Members** (выдавать таймаут)
   - Send Messages
5. Пригласи бота по сгенерированной ссылке. Роль бота должна стоять **выше** ролей обычных участников.

### 2. Ключ Anthropic

Возьми API-ключ на [platform.claude.com](https://platform.claude.com) — анализ картинок делает модель `claude-opus-4-8`.

### 3. Запуск

```bash
export DISCORD_TOKEN="токен_бота"
export ANTHROPIC_API_KEY="ключ_anthropic"
python bot.py
```

(или скопируй `.env.example` в `.env` и подгружай любым удобным способом)

## Настройка (`config.json`)

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `categories` | 5 категорий | Запрещённые категории и их описания для модели |
| `max_warnings` | `3` | Сколько предов до наказания |
| `timeout_minutes` | `60` | Длительность таймаута |
| `delete_notice_seconds` | `15` | Через сколько секунд удалять уведомление в канале |
| `ignore_moderators` | `true` | Не проверять тех, у кого есть право Manage Messages |
| `log_channel_id` | `null` | ID канала для логов модерации (embed о каждом удалении) |
| `max_file_size_mb` | `10` | Максимальный размер файла для анализа |

Предупреждения хранятся в `warnings.json` рядом с ботом и переживают перезапуск.

## Как это работает

1. `on_message` — бот собирает все картинки из вложений, embed'ов и ссылок в тексте.
2. Для ссылок Tenor/Giphy бот ждёт ~2 секунды, пока Discord подгрузит embed с картинкой, и перечитывает сообщение (`on_message_edit` тоже отслеживается).
3. Файл скачивается и отправляется в Claude (`claude-opus-4-8`) со структурированным JSON-ответом: `{violation, category, reason}`.
4. При `violation: true` — удаление, пред, при лимите — таймаут, запись в лог-канал.

## Ограничения

- **Видео** (mp4/webm) не анализируются — только изображения и GIF.
- Крупные GIF анализируются по кадрам, которые видит модель; очень длинные гифки могут быть оценены по первым кадрам.
- Каждая проверка — это запрос к Claude API (тратит токены). Для очень активных серверов можно поменять модель в `bot.py` на более дешёвую `claude-haiku-4-5`.
