# Felar

Мессенджер в стиле Discord: серверы, текстовые каналы и обмен сообщениями в
реальном времени через WebSocket.

![stack](https://img.shields.io/badge/node-22-informational) ![ws](https://img.shields.io/badge/realtime-websocket-5865f2)

## Возможности

- 🔐 **Регистрация и вход** — JWT-токены, пароли хешируются через bcrypt.
- 🏠 **Серверы (гильдии)** — создание своего сервера и вход в чужой по коду-приглашению.
- `#` **Текстовые каналы** — несколько каналов на сервер, создаёт владелец.
- ⚡ **Реалтайм** — сообщения, индикатор «печатает…» и статусы онлайн через WebSocket.
- 👥 **Список участников** с делением на «в сети» / «не в сети».
- 💾 **История сообщений** хранится в SQLite и подгружается при открытии канала.
- 🎨 **Тёмная тема** в узнаваемом стиле Discord, адаптив под мобильные.

## Стек

| Слой      | Технологии                                    |
|-----------|-----------------------------------------------|
| Backend   | Node.js, Express, `ws` (WebSocket)            |
| Хранилище | SQLite (`better-sqlite3`)                     |
| Auth      | `jsonwebtoken`, `bcryptjs`                     |
| Frontend  | Ванильный JS (SPA), CSS без фреймворков        |

## Запуск

```bash
npm install
npm start           # http://localhost:3000
```

Переменные окружения (необязательно):

- `PORT` — порт сервера (по умолчанию `3000`).
- `JWT_SECRET` — секрет для подписи токенов (задайте свой в проде).

### Быстрая проверка

1. Откройте `http://localhost:3000`, зарегистрируйтесь.
2. Нажмите **+** на левой панели → «Создать сервер».
3. Скопируйте код-приглашение (под списком каналов), откройте второе окно в режиме
   инкогнито, зарегистрируйте второго пользователя и войдите по коду.
4. Пишите сообщения — они доставляются мгновенно.

## Структура проекта

```
server/
  index.js     точка входа: Express + HTTP + WebSocket
  db.js        схема и подключение SQLite
  auth.js      хеширование паролей, JWT, middleware
  routes.js    REST API (auth, серверы, каналы, история)
  ws.js        обработка WebSocket-соединений
  hub.js       реестр соединений и broadcast-хелперы
public/
  index.html   разметка SPA
  css/style.css оформление
  js/app.js    клиентская логика
```

## REST API (кратко)

| Метод | Путь                             | Назначение                     |
|-------|----------------------------------|--------------------------------|
| POST  | `/api/auth/register`             | регистрация                    |
| POST  | `/api/auth/login`                | вход                           |
| GET   | `/api/me`                        | текущий пользователь           |
| GET   | `/api/servers`                   | список серверов пользователя   |
| POST  | `/api/servers`                   | создать сервер                 |
| POST  | `/api/servers/join`              | вход по коду-приглашению       |
| GET   | `/api/servers/:id/members`       | участники сервера              |
| POST  | `/api/servers/:id/channels`      | создать канал                  |
| GET   | `/api/channels/:id/messages`     | история сообщений              |

Сообщения, индикатор набора и presence передаются по WebSocket (`/ws?token=…`).
