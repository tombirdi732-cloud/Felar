# FELAR — сказка об угасшем свете

Атмосферный браузерный платформер: лесной дух-фонарщик Фелар собирает
осколки упавшей звезды, чтобы вернуть миру свет. Три главы, в каждой —
новая способность:

| Глава | Мир | Способность |
|-------|-----|-------------|
| I | Угасший лес | базовые прыжки |
| II | Хрустальные пещеры | двойной прыжок |
| III | Небесная цитадель | рывок |

## Запуск

Нужен любой статический сервер (из-за загрузки картинок):

```bash
npx http-server .        # или python3 -m http.server
```

и открыть `http://localhost:8080` (порт зависит от сервера).

## Управление

- **← → / A D** — движение
- **Пробел / W / ↑ / Z** — прыжок (в воздухе ещё раз — двойной прыжок)
- **Shift / X** — рывок
- **E / Enter** — диалоги / подтверждение
- **Esc** — пауза, **Q** в паузе — выход в меню

## Графика

Сейчас игра работает на **процедурных анимированных плейсхолдерах**.
Финальные ассеты подключаются простым добавлением PNG-файлов — пути,
размеры, раскладка спрайт-листов и готовые промты для генерации: **[ASSETS.md](ASSETS.md)**.

## Структура

```
index.html         — точка входа
css/style.css
js/config.js       — константы, манифест спрайтов, палитры глав
js/input.js        — клавиатура
js/engine.js       — аниматор, камера, частицы, процедурный звук
js/assets.js       — загрузка PNG + генерация плейсхолдеров
js/entities.js     — игрок, мотылёк, враги, платформы, предметы
js/levels.js       — карты трёх глав (ASCII-экраны) и диалоги
js/game.js         — состояния, игровой цикл, рендер, UI
assets/            — сюда кладутся PNG-ассеты (см. ASSETS.md)
```

## Редактирование уровней

Уровни собраны из «экранов» 24×18 тайлов в `js/levels.js` — обычные ASCII-карты
(легенда в шапке файла). Чтобы удлинить главу, просто добавь экранов в массив.

## Сохранения

Прогресс (открытые главы, лучшее время и осколки) хранится в `localStorage`.
