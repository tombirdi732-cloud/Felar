# Discord-бот модерации медиа 🛡️

Бот следит за отправкой **изображений, GIF и ссылок на гифки** (Tenor/Giphy, прямые ссылки на картинки). Каждое медиа анализируется **бесплатной локальной нейросетью CLIP** — без API-ключей, подписок и оплаты. Если найдена политика или другой запрещённый контент:

1. 🗑️ сообщение **удаляется**;
2. ⚠️ автору выдаётся **предупреждение** (в канале + в ЛС);
3. 🔇 после лимита предупреждений (по умолчанию 3) — **таймаут** (по умолчанию 60 минут).

> Discord не позволяет ботам блокировать сообщение *до* отправки — бот удаляет его сразу после появления (обычно за 1–2 секунды).

## Чем анализируются картинки

Моделью [CLIP](https://huggingface.co/openai/clip-vit-base-patch32) (OpenAI, open-source). Она скачивается **один раз** с HuggingFace (~600 МБ) при первом запуске и дальше работает полностью офлайн на твоём компьютере/сервере. Работает на обычном CPU (~0.1–0.5 сек на картинку); видеокарта подхватывается автоматически, если есть.

Принцип: картинка сравнивается с текстовыми описаниями запрещённых категорий («политический митинг», «порнография»...) и описаниями нормального контента («мем», «аниме», «скриншот игры»...). Если запрещённая категория побеждает с уверенностью выше порога — это нарушение.

## Категории (настраиваются в `config.json`)

| Ключ | Описание |
|---|---|
| `politics` | политики, митинги, лозунги, партийная символика, пропаганда |
| `nsfw` | обнажёнка, порнография |
| `violence` | кровь, жестокость, насилие |
| `extremism` | нацистская/террористическая символика |
| `drugs` | наркотики |

Каждая категория — это набор английских промптов для CLIP (по-английски модель работает точнее). Можно добавлять свои категории и промпты.

## Установка

```bash
pip install -r requirements.txt
```

> ⚠️ `torch` весит ~2 ГБ. Если ставится долго — можно взять CPU-сборку полегче:
> `pip install torch --index-url https://download.pytorch.org/whl/cpu`

### 1. Создай бота в Discord

1. [Discord Developer Portal](https://discord.com/developers/applications) → **New Application**.
2. Вкладка **Bot** → скопируй **Token**.
3. Там же включи **Message Content Intent** и **Server Members Intent** (обязательно!).
4. Вкладка **OAuth2 → URL Generator**: scope `bot`, права:
   - View Channels, Read Message History
   - **Manage Messages** (удалять сообщения)
   - **Moderate Members** (выдавать таймаут)
   - Send Messages
5. Пригласи бота по сгенерированной ссылке. Роль бота должна стоять **выше** ролей обычных участников.

### 2. Запуск

```bash
export DISCORD_TOKEN="токен_бота"
python bot.py
```

При первом запуске подожди, пока скачается модель (~600 МБ, только один раз).

## Настройка (`config.json`)

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `categories` | 5 категорий | Запрещённые категории: `label` (для сообщений) + `prompts` (описания для CLIP) |
| `safe_prompts` | 10 описаний | Что считается нормальным контентом |
| `threshold` | `0.5` | Порог уверенности (0..1). Меньше — строже (больше ложных срабатываний), больше — мягче |
| `max_warnings` | `3` | Сколько предов до наказания |
| `timeout_minutes` | `60` | Длительность таймаута |
| `delete_notice_seconds` | `15` | Через сколько секунд удалять уведомление в канале |
| `ignore_moderators` | `true` | Не проверять тех, у кого есть право Manage Messages |
| `log_channel_id` | `null` | ID канала для логов модерации (embed о каждом удалении) |
| `max_file_size_mb` | `10` | Максимальный размер файла для анализа |

Предупреждения хранятся в `warnings.json` рядом с ботом и переживают перезапуск.

## Как это работает

1. `on_message` — бот собирает все картинки из вложений, embed'ов и ссылок в тексте.
2. Для ссылок Tenor/Giphy бот ждёт ~2 секунды, пока Discord подгрузит embed с картинкой, и перечитывает сообщение (`on_message_edit` тоже отслеживается).
3. Файл скачивается и классифицируется CLIP'ом локально; у GIF проверяются первый, средний и последний кадры.
4. При нарушении — удаление, пред, при лимите — таймаут, запись в лог-канал.

## Ограничения

- **Видео** (mp4/webm) не анализируются — только изображения и GIF.
- CLIP — компактная модель: она заметно слабее больших vision-моделей и может ошибаться в обе стороны. Подкручивай `threshold` и промпты под свой сервер:
  - много ложных срабатываний → подними `threshold` до 0.6–0.7 или добавь `safe_prompts`, похожие на ваш обычный контент;
  - пропускает нарушения → опусти `threshold` до 0.35–0.45 или добавь больше промптов в категорию.
- Тонкий политический подтекст (текст на картинке, карикатуры) CLIP может не распознать — он смотрит на изображение, а не читает текст.
